A simple implementation of **combinatoric 8-bit ALU** (originally should be 4-bit because I'll also implement it on a physical breadboard, but in the end decided to code an 8-bit one).

I've self-learned SystemVerilog and wanted a project to broaden my understanding.
In this project, I've used Verilator and GTKWave with Ubuntu OS to write the code in VS Code.

I've fulfilled each component in the part from logic gates for practice, and based on the last OOP course, I put attantion to divide the project into files and use multiple modules from various files.
